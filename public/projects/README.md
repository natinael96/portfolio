# Project preview images

Drop project screenshots here. They're referenced from `src/content/site.ts`
via each project's `image` field (e.g. `image: '/projects/air-qua.png'`).

- **Air Qua** → `air-qua.png` (recommended ~1280×800, 16:10). Until this file
  exists, the project card shows a styled "live site" fallback frame instead of
  a broken image — so it always looks intentional.

Anything in `public/` is served from the site root, so `/projects/air-qua.png`
maps to `public/projects/air-qua.png`.
